덴트웹 싱크매니저 라이트 포터블 - 현장 기능 테스트 완료 버전



- 덴트웹 싱크매니저라이트 이용 과정
    1. 병원이 덴트웹이 설치된 pc에 `덴트웹싱크매니저라이트` 프로그램 설치
    2. 기본값 환경설정 (메디콘텐츠리뉴얼 웹사이트에 접속하여 토큰값을 확인 후 프로그램에 최초 1회 입력)
    3. 이후 병원이 해당 웹사이트에서 콘텐츠 제작 요청 시 덴트웹의 환자번호만 입력하면 정보가 일괄적으로 포함되어 콘텐츠 제작 요청건이 전송됨

현재 본 프로그램이 이미지를 전송하는 타겟 서버는 cloudflare의 medi-send.com으로 되어있음

추후 개선 작업 시 고려해야 할 점


<마이그레이션 관련>
- aws s3의 스토리지 구조와 cloudflare R2 스토리지 구조가 다소 다르므로 데이터 전송 시의 규격 변경이 필요함
- medi-send.com이 아니라

<일반>
- 테스트 버전은 포터블로 구현되어 보안 경고가 나올 수 있음. inno setup(윈도우 설치프로그램 패키징 툴)을 통해 설치형으로 만들면 해결될 수 있음
- 본 프로그램 구동을 위해 런타임 (닷넷10) 설치가 필요함. 이 또한 inno setup을 통한 설치형 빌드 혹은 닷넷 포함 패키징으로 해결할 수 있음
- 자동업데이트 기능이 있다면 편리할 수 있음
- 현재 서버 비용 절감을 위해 본 프로그램이 1분 단위로 pull 통신을 하고 있음. 병원에서 콘텐츠 전송을 눌렀을때 본 프로그램이 요청을 1분 주기로 재확인하는 개념임. 적절한 수준으로 변경하면 비용을 대가로 높은 응답성을 얻을 수 있음.
